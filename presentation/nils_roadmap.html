In development

  • Pre / post-contrast detection from the image itself
  • Intensity- & distribution-based QC
  • Outlier & mislabel surfacing

Image-Based Contrast QC

An early-stage algorithm using voxel intensity & distribution

Voxel intensities
Distribution features
Pre vs post-contrast
Flag mismatches
Metadata alone often can't tell pre- from post-contrast. By reading the distribution of voxel intensities in enhancing regions, NILS can verify the contrast label against the pixels — and feed disagreements straight into the existing draft-based QC review.

Early stage — the framework is in place; accuracy & calibration are the active work

Photon-Counting CT

A priority frontier for next-generation CT

Why it matters

  • Spectral / multi-energy output
  • Material-decomposition reconstructions
  • New series types per acquisition

What NILS adds

  • Recognize PCCT reconstructions & energy bins
  • Multi-output handling (like MR branches)
  • Consistent BIDS-style organization
PCCT reuses the same provenance-branching pattern proven on multi-output MR — one acquisition, many reconstructions, each classified correctly

Agentic Curation Next

Intelligence at the decision points of data curation

Curation reaches a
decision point
Agent proposes
a refinement
Reviewer
approves
NILS applies it
Classification depends on keywords. At multilingual sites and with site-specific acronyms, the agent can read the local nuance and intelligently adjust how NILS classifies — building on today's per-cohort keyword overrides.

Example: Smarter Keyword Tuning

Agent observes

  • Many "VOLUM" series stuck in review
  • Local term for an MPRAGE protocol
  • A Swedish abbreviation for contrast

Agent proposes

override:
  axis: technique
  bucket: techniques.MPRAGE.keywords
  added: ["volum"]
# scoped to this cohort only
The override mechanism already exists — the agent makes proposing the right change automatic, while the human stays in control of applying it

Pipeline Ecosystem Next

From a few templates to a community of importable analyses

Curated templates

  • Common tools we use most (QC, conversion, preprocessing)
  • Reference descriptors that show best practice
  • Demonstrate how results flow back into NILS

Bring your own

  • Anyone writes a pipeline & imports it by Git URL
  • Boutiques + x-nils descriptor — no NILS UI code
  • Pinned commit & image digest for reproducibility

Unified Query Later

Manual precision and agentic ease, over one data layer

Manual query

  • Structured filters across axes, modalities, clinical metadata
  • Exact, reproducible, shareable selections

Agentic query

  • Ask in natural language; agent builds the query
  • Refine conversationally, then hand off to manual mode
Both modes resolve to the same selection manifests that drive export & analysis pipelines
